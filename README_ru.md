# 🟣 Twitch Chat in Minecraft

Мод для Minecraft который выводит чат с Twitch прямо к тебе в игру.  
Только ты видишь сообщения — другие игроки на сервере ничего не замечают.

Language: (EN)[https://github.com/san5ezez/Twitch-Chat-in-Minecraft/blob/main/README.md] (RU)[https://github.com/san5ezez/Twitch-Chat-in-Minecraft/blob/main/README_ru.md]

---

## ✅ Для чего это нужно

Ты стримишь Minecraft и хочешь читать чат Twitch не переключаясь из игры.  
Мод показывает сообщения прямо в чате Minecraft в реальном времени.

```
[Twitch] viewer123: привет стример!
[Twitch] coolguy: gg wp
[Twitch] fanboy99: когда следующий стрим?
```

## 🔧 Установка

1. Установи **Fabric** или **NeoForge** для своей версии Minecraft
2. Скачай **Fabric API** и положи в папку `mods/`
3. Скопируй файл мода `twitchchat-*.jar` в папку `mods/`
4. Запусти игру

---

## 🎮 Команды

| Команда | Что делает |
|---------|------------|
| `/twitch channel <название>` | Установить канал Twitch |
| `/twitch start` | Начать получение чата |
| `/twitch stop` | Остановить |
| `/twitch status` | Показать текущий статус |

> Также работает `/twich` (с одной `t`) — на случай опечатки.

---

## 🚀 Быстрый старт

```
/twitch channel твойканал
/twitch start
```

Всё. Чат пошёл.

---

## ❓ Как это работает

Мод подключается к Twitch IRC анонимно — **без токена и авторизации**.  
Используется стандартный анонимный логин Twitch (`justinfan`), который позволяет  
читать публичный чат любого канала без регистрации.

Сообщения отображаются **только у тебя** через системный чат Minecraft.  
На сервер ничего не отправляется, другие игроки ничего не видят.

---

## ⚠️ Важно

- Мод работает только на **клиенте** — на сервер ставить не нужно
- Нужно интернет-соединение
- Канал должен быть **публичным**
- Мод читает чат, но **не может писать** в Twitch

## 🛠️ Сборка из исходников

Требования: **Java 21**, **Gradle 9.4.1**

```bash
# Fabric 26.1
cd twitchchat-fabric-261
gradle build
# jar будет в build/libs/

# NeoForge 1.21.1
cd twitchchat
gradle build
# jar будет в build/libs/
```
